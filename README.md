# EcomInsight-Lab

## E-Commerce Data Analysis & Business Intelligence

A complete Python-based e-commerce data analysis project covering sales performance, customer behavior, product and SKU analysis, refunds and returns, and payment channel performance.

![E-Commerce Dashboard](reports/01_performance_overview.png)

### Project Highlights

- 584K+ transaction records analyzed
- 408K+ unique orders
- 115K+ customers
- Sales, customer, product, refund, and payment analysis
- Interactive Streamlit dashboard
- Cleaned and validated e-commerce dataset
- Business-focused insights and KPIs

### Technologies

`Python` `Pandas` `NumPy` `Matplotlib` `Streamlit` `Jupyter Notebook`
